## Context
Acest repository conține transcrierea originală (restaurată în LaTeX) a Tezei de Licență susținute la Universitatea din București în 1999: *Dimensiunea Coireductibilă a Inelelor și Modulelor*.

Proiectul servește drept arhivă digitală și bază pentru traducerea modernizată în limba engleză.

Digitalizată și restaurată în 2025.
